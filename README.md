# Governança de TI · estudos

Anotações dos meus estudos de **Governança de TI e GRC** (Governança, Riscos e Compliance): ITIL, COBIT, gestão de riscos, ISO/IEC 27001, LGPD e Governança de IA.

Trabalho com suporte técnico num provedor de internet e estudo governança para entender melhor o "porquê" das coisas que vejo no dia a dia: incidentes, mudanças, indicadores, riscos. Escrever com as minhas palavras é o jeito que encontrei de fixar o conteúdo. Deixo aberto caso ajude mais alguém que esteja começando.

## Como as notas são feitas

1. Assisto à aula e anoto no Obsidian.
2. Reviso as anotações, completo os pontos que ficaram vagos e organizo no mesmo modelo ([modelo-de-nota.md](modelo-de-nota.md)), com apoio de IA para revisar e complementar.
3. A versão limpa vem para cá.

Cada nota tem: o que é · explicação simples · exemplo num provedor fictício · pegadinhas de prova · perguntas de revisão · fonte.

> Os exemplos usam sempre uma empresa fictícia (**ProvedorX**). Nenhum dado real de empresa aparece aqui.
> As notas são resumos com minhas palavras; o crédito de cada aula vai para quem ensinou (link na seção "Fonte" de cada nota).
