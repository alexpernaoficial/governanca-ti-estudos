# Imersão Databricks + Claude Code (Jornada de Dados)

Fonte: Jornada de Dados, 4 dias, out/2026. Resumo com as minhas palavras.

## Em uma frase
Dado organizado em camadas e critérios definidos antes de pedir ajuda à IA geram indicadores em que dá para confiar.

## Dia a dia
1. **Dia 1.** Unir dados de Excel, ClickUp e Project, noções de SQL, tabelas bronze e custo do atraso (SPI e CPI). IA sem critério definido dá respostas inconsistentes.
2. **Dia 2.** Python, ETL a partir de API e de AWS S3 (boto3), jobs e agendamento. Chaves nunca vão para o GitHub.
3. **Dia 3.** Camadas medallion, validação dos dados e dashboard.
4. **Dia 4.** Databricks Apps (Streamlit) e um agente de IA que responde perguntas de negócio. Planejar antes de pedir para a IA construir.

## O que isso significa na prática (ProvedorX fictício)
- Antes de montar o painel de KPIs do ProvedorX, padronizar as planilhas de churn, SLA e NPS.
- Definir o que é "projeto ruim" (ou "chamado crítico") antes de automatizar o alerta.
